Chinese editor in DOS implemented in C

You can edit both Chinese and English text in most common format.


Note:
This is our course project, we implemented a Chinese text editor in DOS.
Since there is no Chinese in DOS, we design a simple Chinese input spelling.
To draw the GUI of the text editor, we use the BGI(Graphics Driver for Borland C).

What is more, we use the DOS Box to simulate the DOS environment in Windows.

To use it, you may download TC3.0 here(http://thefunplace.co.uk/topic/7965-download-tc-30-for-windows-7/)
